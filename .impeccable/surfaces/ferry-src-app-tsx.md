# Surface brief: the phone app (all screens)

Scope: the whole PWA (pairing, the rack, session chat/terminal, board, Mac). Mode: Operate.
Audience: the owner, one-handed, away from the desk. Job: notice what waits, answer it, read and prompt.
Constraints: PRODUCT.md (honest state, desktop decides, 44pt targets, AA in both themes).
Chosen: world "Sorting Frame" (direction round, THE ROLL) + layout "The Rack" (surface round, dealt).
Reference sketch: .impeccable/mocks/decision/surface-rack.html; full mockup: design/option-b/.

## Direction contract

THESIS: Agents are slots in a sorting frame; whatever needs you pushes a vermilion tab out past the right edge, so the right edge of any list is the queue. Refuses the grey list with red badges.
OWN-WORLD: Enamelled frame-green shell (header, filter, tab bar), pale steel-grey ground, slot cards built from hairlines and one soft shadow, brass label plates with typewriter designators (PAN·1) identical everywhere, vermilion quarantined to tabs and answer cards, hatched rules for stale state, working time drawn as rule length.
STORY: Open, see every project shelf; the tabs say what waits and why; tap one, answer the plan/question/permission in the chat; flip to Terminal when needed; drag work across the board.
FIRST VIEWPORT: Frame header with Mac name and live link state; All / Need you / Working segmented filter; shelves (typewriter caps project label + path + Board link) of slot rows: plate, title, agent + one-line status, state + duration rule on the right or a tab. Tab bar: Sessions (count) · Board · Mac.
